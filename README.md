# t20-batsmas-stands
Overview:
Developed an interactive Power BI dashboard to analyze T20 cricket batsmen performance across multiple parameters such as runs, strike rate, and partnerships. The project provides a clear visualization of player statistics and team contributions, helping users identify top-performing players and trends.




Key Steps & Tasks:

Performed data cleaning and transformation using Power Query to remove duplicates, handle missing values, and standardize formats.
Designed a data model with relationships between tables to ensure smooth data flow and accurate calculations.
Created DAX measures for calculating total runs, average strike rate, partnerships, and player consistency.
Built interactive dashboards with slicers, filters, and visuals like bar charts, pie charts, and KPIs for deeper insights.
Used Performance Analyzer and DAX Studio to optimize report load time and query performance.
Ensured proper Data Governance by maintaining a structured report layout and naming conventions.



Tools & Technologies:
Power BI, DAX, Power Query, SQL (for data preparation), Excel (for initial data handling)




Key Outcomes:

Delivered an insightful, easy-to-navigate dashboard highlighting key batting trends.
Enhanced report performance and visualization clarity through optimization techniques.
Demonstrated strong analytical, visualization, and data storytelling skills.
